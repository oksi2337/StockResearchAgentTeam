# 주식 리서치 정리 스킬

리서치 에이전트(`/company-research`)가 만든 마크다운 파일을 받아서 정리된 Excel로 변환하는 스킬입니다.

## 입력 파일 구조

```markdown
# 학습 기업 | TSMC TSM
> 작성일: 2026-04-26

| 항목 | 내용 |
|------|------|
| 주간 성과 | -0.02% |
| 주간 주가 변동 주된 사유 | ... |
| 주가의 위치 (단기) | ... |
| 주가의 위치 (중장기) | ... |
| 기업 경쟁력 | ... |
| 포워드 밸류에이션 추정 | ... |
| 최근 일주일간 기업펀더멘털 변화 | ... |
| 향후 전망 | ... |

### 주간 증권사 평가
- [TICKER] (증권사) 투자의견, ... + 목표주가, ...
- ...

### 주요 뉴스
- **뉴스 제목1**: 내용 요약 1~2문장
- **뉴스 제목2**: 내용 요약 1~2문장
- ...
```

파일은 보통 `research/[티커]_[YYYYMMDD].md` 경로에 저장되어 있습니다.

## 두 가지 출력 모드

### 1. 개별 모드 (Individual)
종목 한 개당 한 파일. 한 페이지 요약 표 형태.
- **증권사 평가는 1건당 1행**으로 펼쳐서 표시 (라벨 컬럼은 세로 병합)
- 출력: `output/[티커]_[YYYYMMDD].xlsx`
- 용도: 보고/공유/발표

### 2. 누적 모드 (Portfolio)
2개 시트로 구성:
- **Summary 시트**: 한 종목 = 한 행 (12개 컬럼, 비교/필터링용)
- **Ratings 시트**: 평가 1건 = 한 행 (증권사/투자의견/목표주가가 컬럼별로 분리됨)

같은 (티커, 작성일) 조합은 **갱신**(중복 안 쌓임), 새 조합은 **추가**됩니다.
- 출력: `output/portfolio_master.xlsx` (또는 사용자 지정)

## 사용 방법

### 개별 모드

```bash
python skills/stock-research-formatter/scripts/make_individual.py \
    research/TSM_20260426.md \
    output/TSM_20260426.xlsx
```

### 누적 모드 — 한 종목 추가/갱신

```bash
python skills/stock-research-formatter/scripts/make_portfolio.py \
    research/TSM_20260426.md \
    output/portfolio_master.xlsx
```

### 누적 모드 — 폴더 일괄 추가

```bash
python skills/stock-research-formatter/scripts/make_portfolio.py \
    --bulk research/ \
    output/portfolio_master.xlsx
```

## 사용자 요청 → 명령 매핑

| 사용자 요청 | 실행 |
|--|--|
| "TSM 리서치 엑셀로 정리해줘" | 개별 모드 |
| "TSM 포트폴리오에 추가" | 누적 모드, 단일 |
| "이번 주 리서치한 거 다 묶어줘" | 누적 모드, `--bulk` |
| "이번 주 종목 비교표 만들어줘" | 누적 모드, `--bulk` |

티커만 주어졌고 날짜가 없으면 `research/[티커]_*.md` 중 가장 최신 파일을 사용합니다.

## Ratings 시트 컬럼 상세

증권사 평가는 자동으로 다음 컬럼으로 분리됩니다:

| 컬럼 | 추출 방법 | 예시 |
|--|--|--|
| 증권사 | 첫 괄호 `(...)` | "BofA", "Aletheia" |
| 투자의견 | "투자의견, XXX" | "Buy", "Outperform" |
| 의견 변경 | 투자의견 뒤 괄호 | "유지", "상향" |
| 목표주가 | "목표주가, XXX" 본문 | "$480.00 ← $410.00" |
| 목표주가 변경 | 마지막 괄호 | "상향", "유지", "하향" |
| 원문 | 파싱 안 된 경우 대비 원본 보존 | 전체 텍스트 |

## 디자인

### 개별 모드
- 헤더: 진한 그린(#7BAE7F) + 흰 글씨, "💡 학습 기업 | 회사명 (티커) · 날짜"
- 라벨 컬럼: 민트(#D9E8D4), 가운데 정렬, 굵게
- 내용 컬럼: 좌측 정렬, 불릿(•) 자동 추가
- 주간 성과: 양수=빨강, 음수=파랑 (한국식)
- 평가 라벨: 평가 개수만큼 세로 병합

### 누적 모드 (Summary 시트)
- 12개 컬럼, 1행 헤더 고정 (freeze pane)
- 짝수 행 옅은 배경 (zebra striping)

### 누적 모드 (Ratings 시트)
- 9개 컬럼, 1행 헤더 고정
- 의견/목표가 변경: 상향=빨강, 하향=파랑

## 동작 요건

- Python 라이브러리: `openpyxl`
- 입력 md는 리서치 에이전트(`/company-research`)가 생성한 표 구조를 따라야 함

## 뉴스 섹션

### 개별 모드
- 증권사 평가 다음에 "주요 뉴스" 라벨 행 추가 (라벨 세로 병합)
- 각 뉴스 1건당 1행: `◆ [제목]\n   요약` 형식, wrap_text=True

### 누적 모드 (Summary 시트)
- "뉴스 건수" 컬럼(13번째) 추가 — 뉴스 개수만 기록, 내용은 개별 모드에서 확인

## 누락 항목 처리

리서치 에이전트의 placeholder(`✏️ **직접 입력**` 또는 `확인 필요`)는 빈 값으로 처리되며, 개별 모드 엑셀 하단에 ⚠️ 경고가 표시됩니다.

## 확장 시 주의사항

- 입력 md 템플릿이 바뀌면 `parse_md.py`의 `TABLE_FIELDS` 리스트 동기화 필요
- 누적 모드 컬럼 변경 시 `make_portfolio.py`의 `SUMMARY_COLUMNS`/`RATINGS_COLUMNS`와 `_summary_row`/`_rating_rows` 함께 수정
- 색상은 한국 주식시장 기준(상승=빨강, 하락=파랑). 미국식으로 바꾸려면 `COLOR_UP`/`COLOR_DOWN` 스왑
- 증권사 평가 파싱 정규식은 `make_portfolio.py`의 `_parse_rating_line` 함수에 있음. 새로운 평가 형식이 들어오면 여기서 패턴 추가
